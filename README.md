# OfferPilot 网申助手

面向秋招网申的 Chrome / Edge Manifest V3 插件。资料只保存在当前浏览器，通过标签、占位符、字段名和上下文识别常见网申字段，并在用户确认后填写当前页面。

## 功能

- 上传 PDF / DOCX / TXT 简历，本机解析后自动填充个人信息与经历
- 多套求职档案，支持基础信息、求职意向与能力信息
- 教育、实习、项目、校园经历等可重复条目
- 通用中英文字段识别、置信度过滤、下拉框与单选框匹配
- 默认只填写空白字段，填写后高亮并显示结果
- 检测简历上传框并提示手动选择文件
- 所有资料使用 `chrome.storage.local` 保存在本机，不上传服务器
- 不会自动提交表单

## 本地构建

要求 Node.js 20 或更高版本。

```bash
npm install
npm run typecheck
npm run build
```

构建结果位于 `dist/`。

## 安装

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `dist/` 目录。

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目的 `dist/` 目录。

## 使用

1. 首次安装会打开资料页。可直接上传简历自动填充，或在导入后微调，等待顶部显示“已保存”。
2. 简历导入支持 PDF、DOCX、TXT / MD，解析过程完全在本机完成，不上传文件。
2. 可为不同岗位或城市新建、复制多套档案。
3. 打开网申表单，点击浏览器工具栏中的 OfferPilot。
4. 选择档案，点击“智能填写当前页面”。
5. 核对所有字段，手动选择简历文件后再提交。

## 已知限制

- 浏览器安全机制禁止扩展程序代替用户选择本地文件，因此插件只检测并高亮简历上传框。
- 验证码、富文本编辑器、级联地区选择器、封闭的跨域 iframe 或高度定制组件可能需要手动处理。
- 通用识别无法保证适配所有招聘系统；填写完成后必须人工复核。
- 简历解析基于版式规则，对两栏排版、表格型简历和扫描版图片 PDF 效果有限，需要人工校正。
- 旧版 `.doc` 需先另存为 `.docx` 或导出 PDF。

## 开发命令

- `npm run dev`：监听源码并持续构建
- `npm run typecheck`：执行 TypeScript 类型检查
- `npm run build`：生成生产构建
